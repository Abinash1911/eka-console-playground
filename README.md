# eka-console-playground

Harness for AI-assisted work on the Eka console and chat widget.

- `CLAUDE.md`: standing rules, loaded every session
- `docs/ecosystem-map.md`: how the repos fit together (draft, marked read / to verify)
- `docs/capability-index.md`: what already exists, partial, or missing
- `docs/build-log.md`: running log of what was built, decisions, open questions
